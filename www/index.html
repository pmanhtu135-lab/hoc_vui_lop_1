Cài đặt lên iPhone

✅ Đã chuẩn bị sẵn toàn bộ dự án iOS Capacitor!

Bấm nút bên dưới để tải file HocVuiLop1-IPA-Project.zip (đã có sẵn www/index.html, package.json, capacitor.config.json và script tự động xuất HocVuiLop1.ipa).

  1. Bước 1: Giải nén tệp .zip vừa tải về.
  2. Bước 2: Đưa lên 1 kho mới trên github.com/new → mở tab Actions để GitHub tự xuất tệp HocVuiLop1.ipa (không cần máy Mac).
  3. Bước 3: Cài HocVuiLop1.ipa vào iPhone qua Sideloadly hoặc AltStore.

Nếu muốn cài ngay trong 30 giây mà không cần xuất .ipa: tải tệp index.html bên dưới → kéo thả lên app.netlify.com/drop → mở link bằng Safari trên iPhone → bấm Chia sẻ (⬆️) → Thêm vào MH chính.
